# 📊 Motorola Mobile Sales Dashboard – Power BI

An interactive **Power BI Sales Analytics Dashboard** built to analyze mobile phone sales, quantity, transactions, customer ratings, payment methods, brands, cities, mobile models, and sales trends.

## 📌 Project Overview

This dashboard provides a visual analysis of mobile sales performance using transaction-level sales data. It helps identify sales trends, customer preferences, top-performing brands/models, payment behavior, and city/day-wise performance.

## 🛠️ Tools & Technologies

- **Power BI Desktop**
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Data Modeling**
- **Data Visualization**
- **Excel/CSV Dataset** – Source data

## 📂 Dataset

The dataset contains transaction-level mobile sales information, including:

- Transaction ID
- Day
- Month
- Year
- Day Name
- Brand
- Units Sold
- Price Per Unit
- Customer Name
- Customer Age
- City
- Payment Method
- Customer Ratings
- Mobile Model

## 📈 Dashboard KPIs

The dashboard presents key performance indicators such as:

- 💰 Total Sales: **769M+**
- 📦 Total Quantity: **19K+**
- 🧾 Transactions: **4K+**
- 📊 Additional sales/transaction KPI: **40K+** as displayed in the dashboard

> KPI values can change when filters/slicers are applied.

## 🎯 Dashboard Features

### 1. Sales by City
Visualizes total sales across different cities to compare geographical performance.

### 2. Quantity by Month
Shows monthly quantity trends and helps identify high- and low-performing months.

### 3. Customer Ratings
Displays the distribution of customer ratings from **1 to 5**.

### 4. Transactions by Payment Method
Compares transactions across:
- UPI
- Debit Card
- Cash
- Credit Card

### 5. Brand Performance Table
Provides brand-wise:
- Total Sales
- Total Quantity
- Transactions

### 6. Sales by Mobile Model
Highlights the top-performing mobile models based on sales.

### 7. Sales by Day Name
Compares sales performance across days of the week.

## 🎛️ Interactive Filters

The dashboard includes slicers for:

- Mobile Model
- Payment Method
- Brand
- Day Name
- Month

These filters allow users to interactively explore the sales data.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Motorola_Mobile_Sales_Dashboard.pbix` using **Power BI Desktop**.
3. If Power BI asks for the data source, update the source path to the dataset in the `data` folder.
4. Use the slicers to explore the dashboard.
5. Select different brands, mobile models, payment methods, months, or days to analyze performance.
